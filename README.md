# 🧭 ChronoPath Animator

An interactive 10-year mobile timeline, heatmap, and multi-modal route visualizer built with Streamlit and Leaflet.

## ✨ Features
- **Interactive Map:** Visualizes GPS history with progressive animations.
- **Multi-Modal Transport:** Automatically classifies flights, trains, road trips, and walks.
- **Heatmap & Stopovers:** Toggles density heatmaps and >30 min stay-point pins.
- **Lifetime Travel Wrapped:** Calculates total distance, Earth laps, top speed, and longest trips.
- **Community Leaderboard:** Ranks users by distance and active travel days.
- **1-Click GPX Export:** Download any trip to load into navigation apps.
- **Admin Dashboard:** Secure data management and user audit logs.

## 🚀 Tech Stack
- **Frontend:** Streamlit, Leaflet.js (Map rendering & Heatmaps)
- **Backend/Data:** Python, Pandas, JSON parsing
- **Security:** SHA-256 Password Hashing
